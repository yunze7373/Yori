# Yori

**Yori by Yonro**  
*A little ahead. By your side.*

Yori is a proactive AI assistant that uses a user's calendar, location, and preferences to help them plan ahead and act at the right moment.

## Project status

Project foundation only. No application has been implemented yet. Platform, technology stack, model integration, and deployment choices remain open.

## Initial validation direction

The proposed first scenario is preparing for and leaving for an appointment:

1. Record a user-confirmed preparation preference.
2. Combine the appointment time, travel estimate, and preparation buffer.
3. Suggest when to prepare and when to leave.
4. Collect feedback to improve subsequent suggestions.

Contextual errands are a possible extension; broader travel planning is a later exploration. These are working hypotheses, not a finalized implementation scope.

## Product principles

- Be useful at the right moment and avoid unnecessary interruptions.
- Make remembered preferences visible, editable, and deletable.
- Obtain appropriate permission for calendar and location access.
- Clearly distinguish simulated demonstrations from real integrations.
- Validate delivery reliability and user value before making performance claims.
